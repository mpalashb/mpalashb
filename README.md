## 🚀 Featured Project

### 🏠 Real Estate Lead Generation System
A complete system built for a property agency (private client project):

- 🕷️ Daily scraping of major property portals
- 📉 Detection of price drops, relistings & private sellers
- 🎯 0–100 lead score with a clear reason for every score
- 📊 CRM dashboard with owner & employee logins
- 📧 Automated email alerts & follow-up tracking

**Stack:** Python · PostgreSQL · FastAPI · HTMX · Tailwind · n8n · Docker

> **Result:** The team now manages all its outreach from one app.
